# 岛屿植被地面组件（`components/island-grass/island-grass-base.tscn`）

一块**和岛屿台面完全同形**的草地底板 + 铺满整块底板的草（带轻微摇曳）。

```
components/island-grass/
├── island-grass-base.tscn      组件场景（拖进任何场景就能用）
├── island_grass_base.gd        组件脚本（底板缩放 / 撒草 / 摇曳参数）
├── grass_sway.gdshader         摇曳 shader（顶点位移 + 世界风向）
├── island_grass_test.tscn      测试场（岛 + 底板 + 草 + 公共相机 + HUD）
├── island_grass_test.gd        测试场脚本（改宽度 / 密度 / 染色 / 摇曳）
└── README.md                   本文件
```

相机和「锁定鼠标」按钮用的是**公共组件**
`components/common/god_viewport/`（和恐龙测试场共用一套）。

## 1. 岛面长什么样（先量出来的）

数据全部来自 `res://assets/models/island/sky-island-basic.glb`（直接读 GLB 的
JSON 块量出来的，不是估的）：

| | 值 |
| --- | --- |
| 台面节点 | `Cubo_44-col`（Godot 导入后带 `-col` → 自带 StaticBody3D） |
| 台面轮廓 | **56 个点**的不规则圆盘 |
| 半径 | **29.5 ~ 34.7 m**（组件岛尺度） |
| 宽（X） | **62.413 m** |
| 长（Z） | **64.688 m** |
| **长宽比** | **1.03645** |
| 面积 | ≈ 3000 m² |
| 台面高度 | y = 0（组件岛坐标，岩台面） |

岛体本身是一坨"切掉顶面的球"（`Esfera_44`），底下还挂着 21 块浮空的碎石
（`rocas`）；另外还有天空穹顶 / 太阳 / 月亮（`Cielo_Físico`）。
**跟植被有关的只有那块台面**。

## 2. 底板：形状抄岛面，宽可设，长按固定比例

底板 `assets/models/grass/island_grass_base.glb` 是用 Blender 从源 GLB 里
**抠出台面轮廓**再生成的（`assets/models/grass/island_grass_base.py`，
脚本是唯一事实来源）：

- 上表面 = 岛面轮廓**逐点相同**（实测最大偏差 **0.85 mm**，只是浮点取整）
- 底下压 0.6 m，底环朝中心内缩 0.3 m → 侧壁是斜的，**藏进岩石里**，
  岛缘不会支出一圈绿边
- 顶面在 y = 0（= 岛面高度），Godot 侧再抬 `base_lift`（默认 0.03 m）避免 z-fighting

### 宽可设、长按固定比例

```gdscript
@export var width: float = 62.413   # 地面矩形宽（X 方向，米）
# 长度 = width × 1.03645           ← 固定比例，不给改
```

比例 **1.03645** 是岛面自己的长宽比（64.688 / 62.413）。
改 `width` 时整块底板**等比**缩放，所以"底板和岛面同形"这件事**永远成立**。
长度可以用 `get_length()` 读出来。

> ⚠️ 大世界（1414 m 那座）把岛拉成 **水平 22.8 倍 / 竖直 14.8 倍**，
> 本组件是**等比**的，所以它服务的是 62 m 的组件岛；
> 大世界的草走 `scenes-3d/jurassic-island/bake_local_grass.gd` 那条烘焙线。

## 3. 草：减面版 + 两种类型各聚成团

### 3.1 减面（LOD）

铺满一整座岛意味着同一丛草要重复**上万次**，面数直接乘以实例数。
所以先用 Blender 减面（`low_poly_grass.py -- lod`，脚本是唯一事实来源）：

| 资产 | 原版 | 减面版 | 面数比 |
| --- | --- | --- | --- |
| 尖叶草墩 `grass_tuft` | 266 面 | **`grass_tuft_lod` 48 面** | **1/5.5** |
| 圆润灌木草 `grass_clump` | 260 面 | **`grass_clump_lod` 60 面** | **1/4.3** |

减面手法（造型逻辑一点没动）：

1. **沿叶长的段数 4→2 / 3→2** —— 每片叶子的环带从 4~5 圈变 2 圈，
   面数 14 → 6。V 形折痕是**截面造型**，砍段数也还在。
2. **每层根数砍到 45%（草墩）/ 33%（草簇）** —— 少而宽：
   叶宽同时乘 1.40，轮廓不塌。
3. 颜色分层（长度渐变 / 折痕明暗 / 根部 AO / 单叶随机 / 面向打光）**原样保留** ——
   面变少的时候，层次全靠颜色撑。

### 减面之后还得**把根摊开**（铺满地面靠这个）

叶片砍掉一半以后，全都挤在原来那一小圈里，互相叠着：
一丛 8 片叶子占地 0.25 m²，但叶子的投影加起来有 0.4 m² —— **一半是浪费的**。
所以减面版的**根半径 ×1.55**（草墩 0.71×0.36 m → **0.83×0.41 m**，
草簇 0.52×0.37 m → **0.65×0.46 m**）：同样的实例数能盖住大一倍的地面。

| | 减面版占地（地面投影） |
| --- | --- |
| `grass_tuft_lod` | 0.83 × 0.41 m，高 0.76 m |
| `grass_clump_lod` | 0.65 × 0.46 m，高 0.34 m |

配合 `clump_density = 2.0`（每 0.71 m 一团），地面**完全被盖住、不露底板**。

### 3.2 摆放：不混个体，各自成团，团与团交错

```
草地按网格铺开（格子边长 = 1 / sqrt(clump_density)，默认 ≈ 0.71 m）
  ↓ 每格一"团"，团内 blades_per_clump 株草挤在 clump_radius 里（默认 10 株 / 0.45 m）
  ↓ 团的类型按"片"分配：patch_ratio × patch_ratio 团为一片（默认 3×3）
  ↓ 片的类型棋盘式交替 + 每片 25% 概率翻转
```

结果（俯视 + 两种草染成红/蓝验证过）：

- **一株一簇，簇里绝不混两种** ✓
- **两种草各自聚成一片一片的团** ✓
- **片与片犬牙交错**（棋盘 + 随机翻转），不会出现"这边全是 A、那边全是 B"的硬边 ✓
- **地面被完全盖住，不露底板** ✓（见下面"铺满"那一节）

默认参数下的量（62 m 的组件岛）：

| | 值 |
| --- | --- |
| 草团数 | 6007 |
| 草株数 | **59617**（草丛 34559 / 草簇 25058） |
| 三角面 | ≈ 3.2 M（59617 × 48~60） |
| 实测帧率 | **119 fps**（M4 Pro，第一人称视角） |

草**不投影**（`SHADOW_CASTING_SETTING_OFF`），草叶太密，投影不划算。

## 4. 摇曳

`components/island-grass/grass_sway.gdshader`：

- 顶点按**高度平方**往风向下压（根部不动，梢部最大位移 `sway_strength`）
- 每株草有**自己的相位**（`INSTANCE_CUSTOM.x`），所以是一片一阵地晃，不是整齐划一
- 风向是**世界坐标**的（`wind_direction`，XZ 平面），
  但位移发生在实例本地空间 → shader 用每株存下来的
  `cos(转角) / sin(转角)`（`INSTANCE_CUSTOM.y/z`）把世界风向转回本地。
  不做这一步的话，每株草都朝各自方向倒，整片草看着像炸开的蒲公英

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `sway_strength` | 0.06 m | 梢部最大位移。0.03~0.08 是"轻微"，0.15 以上就明显了 |
| `sway_speed` | 1.2 rad/s | 1.0 ≈ 6 秒一个来回 |
| `wind_direction` | (1.0, 0.35) | 世界风向（XZ） |
| `wind_strength` | 1.0 | 风力总开关（0 = 完全不动） |
| `plant_height` | 0.76 / 0.40 | 两种草各自的高度（归一化用） |

## 5. 参数一览

| 参数 | 默认 | 干什么 |
| --- | --- | --- |
| `width` | 62.413 | 地面矩形宽（米）。长度 = 宽 × 1.03645（固定） |
| `base_lift` | 0.03 | 地面顶面抬高（防 z-fighting），草跟着一起抬 |
| `clump_density` | 2.0 | 每平方米几团草（**默认值就是"刚好铺满"**，再稀就露底板） |
| `blades_per_clump` | 10 | 每团几株草 |
| `clump_radius` | 0.45 | 团内几株草散开的半径（米） |
| `patch_ratio` | 3 | 几团合成一片同类型区域（1 = 逐团交错） |
| `grass_scale_min/max` | 0.8 / 1.35 | 草的随机缩放范围 |
| `seed` | 20260915 | 随机种子（同种子 = 同一片草地） |
| `exclude_areas` | `[]` | 不种草的矩形区域（组件局部 XZ）—— 比如山体脚下 |
| `max_instances` | 120000 | 草株数保险丝：地面特别大时自动降密度并打警告 |
| `sway_*` / `wind_*` | 见上 | 摇曳 |

## 6. 怎么用

```gdscript
# 拖进场景，或者代码里实例化
var grass_base := preload("res://components/island-grass/island-grass-base.tscn").instantiate()
add_child(grass_base)
grass_base.width = 62.413          # 地面宽（长度自动 = 宽 × 1.03645）
grass_base.exclude_areas = [Rect2(-17, -20, 28, 21)]   # 山体脚下不长草
```

> 组件**不自带碰撞**：岛面碰撞还是 `sky-island-basic.glb` 自带的那份
> （`Cubo_44-col`，导入即 StaticBody3D）。底板只是"长草的那层土"。
>
> 组件也**不改变岛体地形** —— 它是加在岩台上面的一层植被地面。

## 6.5 测试场 `island_grass_test.tscn`

直接跑这个场景就能看效果：**组件岛的地形**（`terrain.tscn`：岩台 + 山体）
+ **植被地面组件**，两者都在原点，所以一眼能看出"底板和岛面是不是严丝合缝"。

| 键 | 作用 |
| --- | --- |
| `↑` `↓` `←` `→` | 相机前后左右（`Space` 上升 / `Ctrl` 下降） |
| 鼠标右键拖动 | 转视角（`F` 锁定鼠标 = 第一人称手感） |
| `1` `2` `3` `4` | 地面宽度预设：31 / 62 / 125 / 200 m（**长度按固定比例跟着变**） |
| `Z` / `X` | 草密度 −/+（每平方米几团） |
| `R` | 换随机种子（重新撒一遍草） |
| `G` | 两种草染色（红 / 蓝）—— 看清"各自成团、片与片交错" |
| `C` | 摇曳开 / 关 |
| `T` | 地形开 / 关（只看底板和草） |

左上角 HUD 每 0.2 秒刷新：宽度 / 长度 / 固定比例、草密度、草团数、草株数、帧率。

> 改宽度时草会重建（几秒钟），**草量保险丝**（`max_instances`，默认 12 万）会
> 在超出时自动降密度并打警告 —— 宽 125 m 时就会触发（地表面积 ×4）。

## 7. 重建资产

```bash
# 减面版草（顺带重生成原版）
cd assets/models/grass
blender --background --python low_poly_grass.py -- lod

# 岛屿植被地面底板（从源 GLB 抠岛面轮廓）
blender --background --python island_grass_base.py

# 校验四款草的导入结果（面数 / 顶点色 / 落地）
godot --headless --path . --script res://assets/models/grass/verify_grass.gd
```

⚠️ 改了 `.glb` 之后要**重新导入**（`godot --headless --path . --import`），
否则 Godot 用的还是 `.godot/imported/` 里的旧版本。
