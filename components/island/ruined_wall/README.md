# 破败石墙（可拼接）`RuinedWall`

模块化的荒废石墙：**单段 2.90 m 长**，沿本地 **+X** 一段段接下去就是任意长度的废墟墙，
接缝处看不出是拼的。也能直接怼在园区大门的两翼上继续加长（两者是同一份几何）。

- 模型：`assets/models/ruined-wall/low_poly_ruined_wall.glb`
- 生成脚本：`assets/models/ruined-wall/low_poly_ruined_wall.py`
- 共享构建代码：`assets/models/_shared/ruin_kit.py`（墙体尺寸的唯一来源）
- 单段尺寸：**2.90 × 1.54 × 2.25 m**（长 × 厚 × 高）—— 墙厚 0.75 m、基座 0.28 m、压顶 0.20 m，**1.54 m 是含墙脚碎石堆的包络**（墙本身还是 0.99 m 厚）
- 原点：**单段中心**，底面 `y = 0`
- 面数：**2488 三角面**（2 个材质槽：石 / 植物），1:1 米制，不需要任何 scale

## 造型：low-poly「凿石」版（2026-11 重做）

旧版墙身是**一只只正立方体**（砖模数 0.48 × 层高 0.25 × 墙厚 0.75），
颜色还**逐面随机撒绿苔** —— 渲染出来是"我的世界"的积木墙：棱角全是直角、
颜色全是噪点，一点低多边形的味道都没有。

现在换成手工凿石（几何全部在 `_shared/ruin_kit.py`，大门两翼同一份）：

| 做法 | 效果 |
| --- | --- |
| 石块 = **切角块**（`hewn_block`，24 顶点 / 26 面） | 棱角削掉 → 边缘有倒角高光；所有面都是**精确平面**，按棱面上色不会花 |
| 石头**前后深度逐块不同**（±0.13 m） | 墙面是起伏的，不是两张平板 |
| **颜色按整块石头给**，面与面之间只按法线做明暗 | 低多边形的块面感来自**明暗差**，不是彩色噪点 |
| 苔藓长在**朝上的整块棱面**上 | 和 `low_poly_rock` 同一个路子：哪个面朝上，一眼看得出来 |
| 墙身背后有**暗色墙芯** | 缺石处露出的是一块发暗的凹面，不是"看穿墙" → 墙有厚度、有阴影 |
| 压顶 = **一块块石板**（有缺、有厚薄、跟着墙头起伏） | 不再是浮在墙上的"巧克力条" |
| **破损**：缺石（上层更多）/ **贯穿上半段的破口** / 裂成两半的裂石 / 崩掉一角的石头 / 滑出来歪在墙上的石头 / 被侵蚀得高低不齐的层缝 | 墙不再是"砌好的"，而是"塌了一半的" |
| **墙脚碎石**：一堆一堆的碎石（每堆 2~4 块、越往上越小）+ 零星散落的碎块 + 整块倒下来靠着墙的大石头 | 碎块**一半藏进基座、一半露在外面**，坐实"墙是塌出来的"；塌口底下那堆最大 |

### 面数怎么控住的（2488 三角面）

| 零件 | 用哪种石块 | 面数 |
| --- | --- | --- |
| 墙身正面的石头 | **全切角块** `hewn_block`（12 条棱全倒角 → 面面有高光） | 36 三角面/块 |
| 碎石 / 护墙石 / 接缝端石 / 塌口碎石 | **减面版** `hewn_block_lite`（只留顶面倒角） | 20 三角面/块 |
| 墙芯 / 基座 | 方盒子 | 12 三角面/块 |

另外两条省面技巧：

- **墙身石头的底面倒角不要** —— 石头总是压在下一层上（下压 2.5 cm），底边根本看不见，
  但省掉的是 4 个棱面 + 4 个角三角（44 → 36 三角面）。
- **`add_poly()` 丢掉零面积面** —— 退化面在 Godot 里会变成一片黑斑（assets/AGENTS.md §6.9）。

> 代价：减面版石头**正面是平的**（没有竖棱倒角），所以只给"小到看不清棱"的零件用；
> 墙身正面必须留全切角块 —— 平的大面会让整面墙读成"瓷砖墙"。
| 塌口塞碎石头 / 墙脚有护石 / 墙上垂藤蔓 | 破败感来自形体，不来自随机噪点 |

> **切角而不是抖动顶点**：抖动会把面揉成非平面碎片，按棱面上色就花了；
> 切角得到的每一个面都是精确平面，棱线天然干净。

## 两个场景，按需要选

| 场景 | 用途 |
| --- | --- |
| `ruined_wall_run.tscn` | **懒人版**：拖进场景，改 `segments` 就自动往 +X 拼 N 段 |
| `ruined_wall.tscn` | **手工版**：单段，想自己一段段摆 / 精确控制位置时用 |

## 懒人版 `RuinedWall`（`ruined_wall_run.tscn`）

```gdscript
@onready var wall: Node3D = $ParkEntrance/WallEast

wall.segments = 6            # 6 段 = 17.4 m
wall.total_length()          # -> 17.4
```

| 属性 | 默认 | 说明 |
| --- | --- | --- |
| `segments` | `4` | 拼几段（1–40） |
| `mirror_alternate` | `true` | 相邻段交替做 X 轴镜像，错开苔藓 / 塌口的位置 |
| `build_collision` | `true` | 每段挂三角面碰撞 |

**锚点在墙的起点**：第 0 段占 `x ∈ [0, 2.90]`，第 i 段占 `[(i)·2.90, (i+1)·2.90]`。
所以本节点的 `position` 就是"墙从这里开始长"。想让墙朝别的方向，旋转本节点即可。

## 手工版 `RuinedWallPiece`（`ruined_wall.tscn`）

只做一件事：给模型挂碰撞。摆位规则是**相邻两段沿本地 X 间隔 2.90 m**。

## 为什么接缝看不出来

不是靠对齐手调，是靠硬约定 + 脚本内断言（见 `ruin_kit.py` 文件头的「拼接缝契约」）：

1. **长度是砖模数的整数倍** —— `build_wall_segment()` 内部按 `n_bay = round(len/0.48)`
   反算砖宽，所以无论传多长，两端都不会留半块砖。
2. **两端强制满高** —— 墙头本来逐块随机（破败感的来源），
   但端头那块如果也随机，两段接起来就会在墙顶掉一个台阶。
3. **基座 / 压顶在 X 方向不外扩** —— 只朝前后（Y）外扩，X 严格切在 `[xa, xb]`，
   于是相邻两段的基座正好对接成一整条、压顶连成一条脊。
4. **接缝端由一块"端石列"收口** —— 端石逐层码砌、和墙身同一套砌法，
   只是**接缝那一面被切平**；所有墙段共用**同一份模板**（固定种子），
   所以相邻两段的端面**逐点重合**，接缝既没有台阶也没有缝。

错缝为什么能跨缝对上：端石列本身就是逐层错缝的砌法，切平面落在层与层的界上，
相邻两段的端石列拼起来就是连续的砌体。两种情况都跟"镜像"无关 ——
镜像只翻转 X 的方向，层序不变，所以把相邻段镜像放置既增加了外观变化，
又不会破坏接缝。

Blender 端 `verify_seams()` 会数值校验：`min(x) == -len/2`、`max(x) == +len/2`，
且左右两端面的 `(y, z)` 顶点集合完全相等，不满足直接 `AssertionError`。

实测：两端各 **164 个剖面点全等**，接缝最高 **2.22 m**，X 严格切在 **±1.45 m**。
Godot 端实测三段拼起来是 `[0, 2.9]`、`[2.9, 5.8]`、`[5.8, 8.7]`，间隙 0。

## 改尺寸要注意

改 `WALL_LEN_M`（Blender 侧单段长）时，必须同步改
`components/island/ruined_wall/ruined_wall_run.gd` 里的 `SEGMENT_LENGTH`，
否则相邻两段会错位或重叠。墙厚 / 墙高 / 基座 / 压顶则统一改 `assets/models/_shared/ruin_kit.py`，
大门两翼和这里会一起变。

改**造型**（石头大小、切角、配色、苔藓）不用动 Godot 侧：全部参数都在
`ruin_kit.py` 里，改完重新跑一遍 Blender 脚本出 `.glb` 即可。
