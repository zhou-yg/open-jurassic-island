# 恐龙群组件

`components/dinosaurs/dinosaurs.tscn` — **恐龙是运行时放进去的，不是烘死的**。

```gdscript
var herd := $Dinosaurs
herd.initial_count = 100        # 开局放多少只
herd.add_dinosaur()             # 再来一只（按配置的聚居地找地方）
herd.add_dinosaur(0, Vector3(120, 0, -260))   # 指定种类 + 出生点
```

## 为什么不是烘焙

原来的 `world_dinosaurs.tscn` 把每只恐龙的巡逻路线**烘死**在场景里
（每只 24 个路点的固定坐标）。问题：

- 换地形 / 换岛大小都要重烘一遍；
- 路线和场景焊死，场景一挪恐龙就沿着空气走；
- 想改数量只能重烘。

现在路线是**运行时算**的：射线打地面找高度、山体陡坎绕开、树木让开。

## 三层

| 文件 | 作用 |
| --- | --- |
| `dinosaurs.gd` / `.tscn` | 组件本体：数量、池子、出生点、`add_dinosaur()` |
| `dinosaur_species.gd` | 池子里的一项：恐龙场景 + 出现权重 + 领地倍率 |
| `dinosaur_spawn_group.gd` | 一处聚居地：中心 + 半径 + 权重（**支持多个组**） |
| `dinosaur_patrol.gd` | **巡逻计算**：完全不依赖场景，收一个 `World3D` 就能算 |

## 巡逻怎么算（`dinosaur_patrol.gd`）

| 算什么 | 怎么办 |
| --- | --- |
| 路点高度 | 竖直射线打**地面层**，贴地走 |
| 领地大小 | **恐龙偏好**：体型（恐龙场景里 `DinosaurAIConfig.body_size`）→ 领地半径在 `territory_radius_min/max` 之间插值 |
| 走不了的地方 | 坡太陡（山体陡坎）/ 太高（山腰）/ 有树干 → 路点往领地中心收 |
| 出生点 | 聚居地里按 `min_spacing` 摊开，避开树干、陡坡、山腰、岛缘 |

> ⚠️ 树是**先种好的**（烘焙），恐龙后放 —— 所以巡逻和出生点都要自己
> 躲开树干（`tree_clearance`）。以前是树绕着恐龙的路线种，现在反过来。

## 边界围栏

组件会在岛缘内侧 `boundary_inset` 处围一圈**隐形围栏**（边界层，只挡恐龙）：
浮空岛的边缘是悬崖，恐龙掉下去会被送回原地，看起来像"瞬移"。

## 出生点组

不配也行：`spawn_groups` 留空时，组件自己量出岛的半径，在离岛心
0.6 倍半径的一环上摊 6 块聚居地（岛心留给玩家和山体）。

要指定就填 `DinosaurSpawnGroup`：`center` + `radius` + `weight`。
组里满了会自动去别的组找，全满再全岛兜底 —— 所以 `initial_count` 一定放得满。

## 测试 / 体验场景

`dinosaurs_test.tscn` 是**只跑恐龙群**的场地（`dinosaurs.tscn` 旁边）：

- 400 m × 400 m 平地（`Ground` = BoxMesh + BoxShape3D，世界层），没有树 / 山 / 围墙
- 玩家出生在 `(0, 0.94, -20)`，朝北边那组恐龙
- `Dinosaurs` 就是 `dinosaurs.tscn` 的实例，参数按**小场地**调过：
  `initial_count = 18`、领地 20~36 m、间距 14 m、边界围栏内缩 8 m
- 地上的彩色折线 = 每只恐龙**当前算出来的巡逻路线**（颜色按种类区分）
- 左上角 HUD：总数、每种数量、最近三只的状态 + 距离、帧率

F6 直接跑这个场景就能体验，不用进主世界：

| 键 | 作用 |
| --- | --- |
| `1`~`6` | 在玩家面前 10 m 放一只对应种类的恐龙 |
| `0` | 放一只随机种类 |
| `R` | 清空后按 `initial_count` 重新生成 |
| `C` | 清空 |
| `L` | 巡逻路线显示开 / 关 |
| `Esc` | 释放 / 捕获鼠标 |

> 测试场的数值（18 只 / 20~36 m 领地）**只服务于小场地**。
> 大世界仍然是 100 只 / 57~106 m —— 别拿这里的值去改组件的默认值。
