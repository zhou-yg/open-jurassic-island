# 迷宫般风格随机地图

使用元胞自动机实现的迷宫般风格随机地图

默认是较为稀疏的，看起来像是迷宫般的地图

组件入参：
- 迷宫墙壁的基本单元，packedScene
  - 默认使用 csgbox 
- 迷宫地板
- 元胞自动机的相关参数
- 尺寸相关参数
  - 墙壁基本单元长宽，默认 1m x 1m
  - 高度 默认 2m
  - 地图总长度
  - 地图总宽度

- 地图出入口
  - 入口数量
  - 出口数量

随机地图组件约束
- 地势要有连续高度差
- 地图有多个入口，在矩形边缘
- 地图的出口目标在中心

具体实现：components/map/random_map/README.md
