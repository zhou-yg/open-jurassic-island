# 侏罗纪公园海岛的白模地图

使用 csgbox 基本单元搭建

---

## 🎯 任务目标
你是一名 Godot 4.x 技术美术 / 关卡设计师。请根据我提供的**结构化场景描述**，为我生成一份 **GDScript 脚本**，在 Godot 4.x 中运行时**自动生成一个由 `CSGBox3D` 搭建的白模（Whitebox）场景**，用于《侏罗纪公园》主题 Demo 的关卡原型搭建。

---

## 🧱 技术约束（必须遵守）
1. **引擎版本**：Godot 4.x（使用 `CSGBox3D`、`CSGCombiner3D`、`CSGCylinder3D`）。
2. **节点类型**：所有几何体默认使用 `CSGBox3D`，只有在需要圆形结构（如停机坪、游客中心屋顶）时才允许使用 `CSGCylinder3D`。
3. **分组方式**：所有 CSG 节点必须挂载在 `CSGCombiner3D` 下，按区域分组，分组名如下：
   - `TerrainGroup`（地形与海洋）
   - `GateGroup`（大门与游客中心）
   - `WalkwayGroup`（步道与单轨列车）
   - `BaseGroup`（山顶基地与停机坪）
   - `BeachGroup`（沙滩与码头）
   - `NatureGroup`（树木与瀑布）
   - `DinoGroup`（恐龙占位）
   - `PropGroup`（直升机、人物、小船等动态元素）
4. **材质**：全部保持默认白色材质（白模），**不要添加任何纹理、颜色或 PBR 材质**。
5. **脚本形式**：使用一个 `@tool` 脚本（如果方便）或一个在 `_ready()` 中执行的脚本，**用数据驱动的字典/数组来定义每个 Box 的参数**，然后循环实例化节点。每个 Box 定义至少包含：`name`、`position` (Vector3)、`size` (Vector3)、`rotation_degrees` (Vector3，可选)。
6. **单位与比例**：假设 1 单位 = 1 米。整个岛屿边界约 200m × 200m。
7. **坐标系约定**：岛屿中心为原点 (0, 0, 0)；X 轴为左右，Z 轴为前后，Y 轴为高度（向上为正）。

---

## 🗺️ 场景结构化描述（白模搭建依据）

### 1. TerrainGroup｜地形与海洋
- **海洋 Ocean**：扁平大 Box，位于 `(0, -1, 0)`，size `(200, 2, 200)`。
- **主岛底座 Main Island Base**：位于 `(0, 0, 0)`，size 约 `(100, 10, 100)`，代表岛屿最低一层地形。
- **中央裂谷 Central Canyon**：在岛屿中央偏后处，用两个分开的地形 Box 夹出一个 U 型缺口（缺口宽约 20，深约 10）。
- **右侧高地 Hilltop**：在 `(30, 15, -20)` 附近堆叠一个大号 Box，size 约 `(40, 15, 40)`，作为山顶基地平台。
- **左下角悬崖 Cliff**：`(-30, 5, 30)` 处堆叠一个中等 Box，size 约 `(30, 10, 30)`。

### 2. GateGroup｜大门与游客中心
- **主大门立柱 ×2**：位于 `(-30, 8, 0)` 与 `(-25, 8, 0)`，size 各约 `(2, 16, 2)`。
- **主大门横梁**：位于 `(-27.5, 16, 0)`，size `(6, 2, 2)`。
- **大门 Logo 牌**：位于 `(-27.5, 18, 0)`，size `(4, 2, 0.5)`（红色 Logo 用占位 Box）。
- **游客中心主体**：位于 `(-15, 4, 10)`，size `(12, 4, 10)`。
- **游客中心屋顶**：使用 `CSGCylinder3D`，位于 `(-15, 6, 10)`，半径 5，高 1，扁平状。

### 3. WalkwayGroup｜步道与单轨列车
- **高架步道**：从 `(-30, 6, 0)` 延伸到 `(0, 6, 0)`，可拆成 2-3 段细长 Box，size 各约 `(10, 0.5, 2)`。
- **单轨轨道**：横跨中央裂谷，从 `(-5, 10, -5)` 延伸到 `(25, 10, -5)`，size `(30, 0.5, 1)`。
- **列车占位**：位于轨道中段 `(10, 11, -5)`，size `(6, 2, 2)`。

### 4. BaseGroup｜山顶基地与停机坪
- **停机坪**：位于 `(30, 23, -20)`，使用 `CSGCylinder3D`，半径 5，高 0.5，扁平圆盘。
- **停机坪 "H" 标志**：用 3 个小 Box 拼成 H 形，位于圆盘上方 Y=23.3。
- **营房 ×3**：位于停机坪周围 `(22, 23, -25)`、`(38, 23, -15)`、`(25, 23, -12)`，size 各约 `(5, 3, 5)`。
- **瞭望塔**：位于 `(15, 23, -30)`，四根细柱 `(0.5, 6, 0.5)` + 顶部平台 `(4, 0.5, 4)`。

### 5. BeachGroup｜沙滩与码头
- **沙滩**：位于 `(35, 0.5, 35)`，size `(25, 1, 25)`，扁平。
- **码头栈桥**：从 `(40, 1, 40)` 延伸到 `(50, 1, 50)`，size `(2, 0.5, 15)`。
- **帐篷 ×3**：位于沙滩上，size 各约 `(2, 2, 2)`。
- **营火**：位于 `(30, 1, 30)`，size `(1, 1, 1)`。
- **小船**：位于 `(52, 0, 52)`，size `(3, 1, 6)`。

### 6. NatureGroup｜树木与瀑布
- **瀑布**：位于中央裂谷尽头 `(0, 8, -25)`，size `(3, 16, 1)`，垂直细长。
- **树木**：全岛随机散布 30-50 棵，每棵树由两部分组成：
  - 树干：size `(0.5, 3, 0.5)`
  - 树冠：size `(3, 2, 3)`，位于树干顶部
  - 建议用循环在合理范围内随机分布。

### 7. DinoGroup｜恐龙占位（全部用 Box 拼装）
- **霸王龙 T-Rex**：位于 `(-20, 3, -10)`，身体 size `(4, 3, 8)`，头部倾斜 Box。
- **腕龙 Brachiosaurus**：位于中央水域 `(5, 6, 5)`，身体 size `(3, 6, 5)`，脖子为超高倾斜 Box `(1, 8, 1)`。
- **翼龙 Pterodactyl**：天空 `(0, 30, 0)`，两片薄片 Box 做翅膀。
- **水中生物**：左下方海面 `(-40, 0.5, 20)`，一条细长 Box `(2, 1, 10)` 露出水面。

### 8. PropGroup｜动态元素
- **直升机**：位于 `(40, 30, -40)`，机身 size `(4, 3, 6)`，尾梁 `(0.5, 0.5, 5)`，顶部旋翼为两片交叉薄 Box `(12, 0.2, 1)`。
- **人物**：在步道、沙滩、基地、大门附近散布 20-30 个极小 Box，size `(0.5, 2, 0.5)`。

## 📦 输出要求
请输出**完整的、可直接运行的 GDScript 脚本**，包含：

1. 脚本开头声明 `@tool`（可选）。
2. 一个 `_ready()` 函数，在其中调用 `build_scene()`。
3. 一个数据驱动字典 `SCENE_DATA`，按上面的 8 个分组组织，每一项包含 `name`、`position`、`size`、`rotation_degrees`。
4. 一个通用函数 `create_box(parent, data)` 用于根据数据创建 `CSGBox3D` 并设置属性。
5. 一个专用函数 `create_cylinder(parent, data)` 用于创建 `CSGCylinder3D`。
6. 一个辅助函数 `spawn_trees(parent, count)` 用于随机生成树木。
7. 每个 Group 用一个 `CSGCombiner3D` 作为父节点，并设置 `name` 与上面的分组名一致。
8. **代码中不要添加任何注释以外的多余说明文字**，直接输出脚本本体即可。
